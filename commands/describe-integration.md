# Описать интеграцию

1. Классифицировать по [knowledge/integrations.md](../knowledge/integrations.md): REST/OData, HTTP-сервис, web-сервис, JSON, универсальный обмен.
2. Взять соответствующий процесс из [knowledge/processes.md](../knowledge/processes.md) (п. 15–18). Не собирать общий «процесс интеграции».
3. Для REST — только объекты и методы, перечисленные в выжимке. Для HTTP — 404 при несопоставлении шаблона.
4. Обмен XML: можно назвать состав механизма (план обмена, регистрация, сообщения); цикл передачи по шагам в паке отсутствует.
5. Сверка: [../sources/roles-integrations-extensions.md](../sources/roles-integrations-extensions.md). Гл. 15–17 ITS не раскрывать.

Правило: [../rules/integrations.md](../rules/integrations.md).
