# Разобрать регистр

1. Выбрать вид: сведений / накопления / бухгалтерии / расчёта — [knowledge/registers.md](../knowledge/registers.md).
2. Для сведений: независимый vs подчинение регистратору, периодичность, ключ уникальности.
3. Для накопления: остатки vs обороты, приход/расход. Агрегаты не детализировать.
4. Для бухгалтерии: один план счетов, корреспонденция (СчетДт/СчетКт или Счет).
5. Для расчёта: только то, что в выжимке; гл. 12 не проверялась.
6. Движения от документа — [describe-posting.md](describe-posting.md). RLS по измерениям — [check-rights.md](check-rights.md).
7. Сверка: [../sources/objects.md](../sources/objects.md).

Правило: [../rules/registers.md](../rules/registers.md).
