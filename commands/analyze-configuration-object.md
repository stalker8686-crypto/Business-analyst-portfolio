# Разобрать объект конфигурации

1. Определить вид по [knowledge/configuration-objects.md](../knowledge/configuration-objects.md) (таблица видов и ветвь «Общие»). Не создавать новый вид, если его нет в таблице/оглавлении пака.
2. Справочник → [knowledge/catalogs.md](../knowledge/catalogs.md). Документ → [knowledge/documents.md](../knowledge/documents.md) и команда [describe-posting.md](describe-posting.md). Регистр → [analyze-register.md](analyze-register.md).
3. Зафиксировать из пака, что известно: идентификаторы (код/номер, дата), реквизиты vs табличные части, формы по умолчанию vs свои, связь с регистрами. Свойства из оглавления гл. 5 не дописывать.
4. Если нужен процесс разработки/записи — только пункты из [knowledge/processes.md](../knowledge/processes.md) (п. 1, 8).
5. Сверка URL: [verify-sources.md](verify-sources.md), файл [../sources/objects.md](../sources/objects.md).

Правило: [../rules/configuration-objects.md](../rules/configuration-objects.md).
