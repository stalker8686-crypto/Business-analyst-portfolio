# Обработать пробел пака

1. Свериться с разделом «Чего в паке нет» в [knowledge/inventory.md](../knowledge/inventory.md).
2. В ответе явно: «в паке нет / не проверено / за подпиской / HTTP 500», плюс какой URL или глава.
3. Дать только соседний проверенный факт из той же выжимки, без достройки алгоритма.
4. Не предлагать выдуманный синтаксис, полный список прав, оперативное проведение, агрегаты, аннотации расширения.
5. Учётные BPMN не строить.

Правило: [../rules/gaps-its-edt.md](../rules/gaps-its-edt.md).
