# Проверить права

1. Роли пользователя (их может быть несколько) — [knowledge/roles-and-rights.md](../knowledge/roles-and-rights.md).
2. Действие: основное vs интерактивное. Цепочки только из файла (Чтение, Изменение, Удаление, Просмотр, Редактирование, интерактивные удаления).
3. Нужен ли RLS: условие на подмножестве языка запросов по записи/полям. Не писать текст ограничения, если его нет в исходных метаданных задачи и нет в паке.
4. Проведение без права на регистр — п. 14 [knowledge/processes.md](../knowledge/processes.md), не обобщать на все операции.
5. REST: права проверяются, проверка заполнения — нет.
6. Сверка: [../sources/roles-integrations-extensions.md](../sources/roles-integrations-extensions.md). Безопасный режим — пробел ITS.

Правило: [../rules/roles-rls.md](../rules/roles-rls.md). Процессы: п. 12–13.
