# Свериться с источниками

1. Найти факт в выжимке `knowledge/<тема>.md` — должна быть строка «Источник:» с URL и названием раздела.
2. Открыть тематический файл в `sources/` и [sources/README.md](../sources/README.md): статус «проверено публично» / «оглавление ITS» / «недоступен».
3. Если статус не «проверено публично» — не цитировать тело как факт; пометить пробел. Дальше [handle-pack-gaps.md](handle-pack-gaps.md).
4. Дата обращения пака: 2026-09-16. Новую страницу без записи в `sources/` каноном не считать.
5. Не подмешивать форумы и «практику 1С».

Правило: [../rules/rely-on-knowledge.md](../rules/rely-on-knowledge.md).
