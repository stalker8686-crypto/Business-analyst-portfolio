# Описать проведение

1. Прочитать [knowledge/documents.md](../knowledge/documents.md) (разделы «Проведение», «Связь с регистрами»).
2. Отделить: документ проводится / проведение запрещено. Не описывать оперативное проведение и момент времени — в паке нет тела ITS.
3. Регистр-приёмник: вид по [knowledge/registers.md](../knowledge/registers.md). Для накопления и бухгалтерии — регистратор, строка, период.
4. Права на регистр при проведении без доступа у пользователя — только п. 14 в [knowledge/processes.md](../knowledge/processes.md) и [knowledge/roles-and-rights.md](../knowledge/roles-and-rights.md).
5. REST-проведение/отмена — формулировка из [knowledge/integrations.md](../knowledge/integrations.md), без лишних методов.
6. Сверка: [../sources/objects.md](../sources/objects.md). Процессы: п. 6–7, 14.

Правило: [../rules/documents-posting.md](../rules/documents-posting.md).
