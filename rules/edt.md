# 1C:EDT

1C:EDT — среда на Eclipse для конфигураций, расширений, внешних отчётов и обработок; Windows / Linux / macOS; Git.

- Ветку Git можно связать с ИБ; при запуске и отладке выбирается ИБ текущей ветки.
- В паке есть примеры: импорт из Git; «Совместная работа → Сделать проект общим…» → «Фиксировать…» → «Отправить в Upstream». Не подменять их полным Git-workflow.
- CLI: `1cedtcli` / `1cedtcli.exe`; не использовать с рабочими областями младше 2023.1.0; нужны права администратора. Опции и команды — только перечисленные в [knowledge/edt.md](../knowledge/edt.md). Остальное — `help` в конкретной версии или «не проверено».
- `1cedt.ru` / `its.1c.ru/db/edtdoc` — канон. **1cedt.dev** при сборе пака: HTTP 500, не опираться.
- Полное руководство EDT на ITS — заголовок базы, тело не проверялось.

Команда: [../commands/work-with-edt.md](../commands/work-with-edt.md). Процессы: п. 24–26 в [knowledge/processes.md](../knowledge/processes.md).
