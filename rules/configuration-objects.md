# Объекты конфигурации

Структура прикладного решения = состав объектов конфигурации и связи между ними. Не сводить всё к таблицам SQL: разработчик описывает метаданные, объекты языка и запросы; платформа строит таблицы сама.

- Блоки из пака: условно-постоянные данные (константы, справочники, перечисления) → документы (+ журналы, нумераторы, последовательности) → регистры → отчёты и обработки.
- Справочник: код, наименование, реквизиты, табличные части, иерархия, подчинение, предопределённые элементы (пользователь не удаляет и не перемещает). Периодических реквизитов справочника в 8 нет — история через периодический регистр сведений.
- Отчёты и обработки в БД как данные объекта не хранятся; их реквизиты — параметры.
- Пользователь может иметь несколько ролей.
- Не выдумывать свойства из оглавления гл. 5 ITS: тело за подпиской.
