# Язык «1С:Элемент» (1cmycloud)

Опираться на [knowledge/1cmycloud-basic-syntax.md](../knowledge/1cmycloud-basic-syntax.md) и URL в [sources/1cmycloud.md](../sources/1cmycloud.md).

- Это язык **«1С:Элемент»** (справка 1cmycloud, версия 9.1), не встроенный язык платформы 8.3.
- Не смешивать с [knowledge/builtin-language.md](../knowledge/builtin-language.md), запросами 1С:Предприятия и синтакс-помощником ITS/конфигуратора.
- Ключевые слова, модификаторы (`пер`, `знч`, `исп`, `конст`, `метод` …) — только как в выжимке, в нижнем регистре; английские пары — со страницы «Ключевые слова».
- Не дописывать API стандартной библиотеки, которого нет в выжимке.
