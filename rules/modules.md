# Модули

Модули исполняются по событиям, не кодируют всё решение. Перед исполнением компилируются и кэшируются.

- В общих модулях нет переменных модуля и раздела основной программы — только процедуры и функции. Экспорт модуля приложения в общих модулях недоступен; экспорт общих модулей доступен в приложении и других модулях.
- Виды, названные в паке: управляемое приложение, внешнее соединение, сеанс, общие, модуль формы, модуль web-сервиса, обработчики HTTP-сервиса.
- Клиентские процедуры отделяются от серверных. В паке из EDT зафиксированы только `&НаСервере` и `&НаКлиенте` (модуль формы). Полный набор директив гл. 4.8 — за подпиской.
- Привилегированный модуль / `УстановитьПривилегированныйРежим()` — без проверки прав на сервере; не нарушать логику прав пользователя.
- Аннотации расширения Перед / После / Вместо / ИзменениеИКонтроль — только имена из оглавления; поведение не проверялось.
