# Интеграции

Не смешивать механизмы, названные в паке.

- **REST / OData 3.0:** только серверная часть; публикация на веб-сервере; ответы Atom/XML или JSON. Список объектов и методов — как в [knowledge/integrations.md](../knowledge/integrations.md), не дополнять. Ошибки 4XX/5XX.
- **HTTP-сервис:** шаблон URL (в т.ч. `{параметр}`) + метод → иначе 404 → `HTTPСервисЗапрос` / `HTTPСервисОтвет`.
- **Web-сервис:** SOA, операции и XDTO; поставщик через веб-сервер; потребитель — клиентское приложение; MTOM включается автоматически.
- **JSON:** поток, примитивы/коллекции, XDTO прикладных типов. Не выдумывать другие функции сериализации.
- **Универсальный обмен:** только данные (не конфигурацию и не админсведения); XML; план обмена, регистрация изменений, сообщения. Пошагового цикла «отправить/принять» в паке нет — не дописывать BPMN обмена.

Процессы: п. 15–18 в [knowledge/processes.md](../knowledge/processes.md). Команда: [../commands/describe-integration.md](../commands/describe-integration.md).
