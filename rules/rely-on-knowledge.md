# Опираться на knowledge/

Перед ответом по 1С открыть выжимку темы в `knowledge/`, при сомнении — URL в `sources/`.

- Факт только если он есть в файле темы (со ссылкой) или в явно проверенном источнике из `sources/`.
- Имена объектов, прав, методов, опций CLI — как в паке, без перевода и без «привычного» синтаксиса.
- Процесс включать, только если он есть в [knowledge/processes.md](../knowledge/processes.md). Не строить BPMN склада/продаж. Маршрут платформенных бизнес-процессов — только пункты, уже есть в списке.
- Пометки «не проверено / за подпиской», «недоступен» — это стоп: не заполнять пробел. См. [gaps-its-edt.md](gaps-its-edt.md).
- Карта файлов: [knowledge/README.md](../knowledge/README.md), [knowledge/inventory.md](../knowledge/inventory.md).
