# Регистры

Регистры хранят состояния и количества (и при необходимости плановые данные). Не путать виды.

- **Сведений:** измерения + ресурсы + реквизиты; уникальность по ключу записи (в общем случае регистратор, период, измерения). Периодический — поле Период. Подчинение регистратору — если изменения должны быть связаны с документами; ссылка на регистратор обязательна, но запись не обязательно появляется проведением.
- **Накопления:** приход/расход ресурсов; остатки и/или только обороты; уникальность — одна строка одного документа. Агрегаты в паке не раскрыты («Подробнее…») — не описывать устройство.
- **Бухгалтерии:** один план счетов на регистр; с корреспонденцией — СчетДт и СчетКт, без — одно поле Счет. Проводки живут в регистре, не в плане счетов.
- **Расчёта:** в паке только определение (основан на плане видов расчёта). Гл. 12 ITS не проверялась — не добавлять API.
