# Формы, клиент и сервер

Форму можно сгенерировать платформой или задать свою (в т.ч. конструктором: основная vs произвольная). Состав элементов и свойства из гл. 7 ITS — только оглавление: не выдумывать имена свойств.

В клиент-сервере:

- на сервере: запросы, запись, проведение, отчёты, подготовка формы и её запись;
- на клиенте: показ формы, диалог, мелкие расчёты по уже показанным данным, локальные файлы, торговый оборудование.

На клиенте нельзя: работать с БД напрямую, использовать `СправочникОбъект.<имя>`, выполнять запросы. Нужен вызов серверной процедуры.

Данные списков, ТЧ и отчётов уходят на клиент по мере просмотра.
