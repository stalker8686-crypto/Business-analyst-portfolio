# Роли и RLS

Права задаются ролями. Пользователю — одна или несколько ролей. Нет права — действие не выполняется, предупреждение.

- Основные права проверяются всегда; интерактивные — только при интерактивных стандартных операциях. В клиент-сервере все проверки кроме интерактивных — на сервере.
- Не расширять список прав. В паке связаны: Чтение ← Просмотр / Изменение / Удаление; Интерактивное удаление помеченных требует Редактирование, Просмотр, Удаление.
- RLS: чтение, добавление, изменение, удаление + условие. Для регистров накопления, бухгалтерии, расчёта — по измерениям (бухгалтерия — балансовые); для объектов и регистра сведений — по полям (в т.ч. разным полям).
- REST выполняет обычные проверки прав и события, кроме проверки заполнения.
- Безопасный режим и полный список прав объектов — ITS, не проверялись.
