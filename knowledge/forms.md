## Конструктор формы

Конструктор формы объекта конфигурации создаёт формы для отображения данных объекта. Вызывается автоматически при создании новой формы.

Можно создать форму, назначаемую **основной** (специфическое поведение по назначению), или **произвольную** (типовое поведение без специфики прикладного объекта). Визуально задаются реквизиты на форме и вариант командной панели. Результат можно использовать сразу или доработать.

- Источник: [Конструктор формы](https://v8.1c.ru/platforma/konstruktor-formy/). Проверено публично.

Система может автоматически генерировать нужные формы справочников, документов, регистров; разработчик подставляет свои вместо форм по умолчанию.

- Источники: [Справочники](https://v8.1c.ru/platforma/spravochniki/), [Документы](https://v8.1c.ru/platforma/dokumenty/), [Регистр сведений](https://v8.1c.ru/platforma/registr-svedeniy/).

## Состав формы по оглавлению гл. 7 (8.3.26)

Публично доступно **оглавление**, не полный текст. Именованные части:

- Реквизиты формы: типы данных формы; преобразование данных прикладных объектов в данные формы и обратно.
- Специальные типы реквизитов: динамический список (в т.ч. раздел «Ограничения и особенности»); форматированный документ; планировщик; диаграммы.
- Параметры формы, в т.ч. стандартные параметры.
- Команды формы.
- **Модуль формы**.
- Элементы: поле, декорация, таблица, кнопка, группа (обычная группа, командная панель); связь элементов с реквизитами; условное оформление; правила размещения; адаптация к мобильному клиенту.
- Командный интерфейс формы.
- Работа из встроенного языка: открытие формы, переопределение открываемой формы, модификация реквизитов/команд/элементов, динамический список, перетаскивание, подходы к модальности.

- Источник: [Глава 7. Формы](https://its.1c.ru/db/v8326doc/bookmark/dev/TI000000391). Оглавление проверено; правила размещения, ограничения динамического списка, стандартные параметры — **не проверено / за подпиской**. Не выдумывать имена свойств элементов.

## Клиент и сервер при работе форм

Подготовка данных форм, расположение элементов, запись данных форм после изменения выполняются **на сервере**. На клиенте отображается уже подготовленная форма, ввод данных и вызовы сервера. Данные списков, табличных частей и отчётов передаются не сразу, а по мере просмотра.

На клиенте встроенный язык можно использовать для расчётов по отображённой форме (пример: сумма строки по цене и количеству без обращения к серверу), вопросов пользователю, чтения локального файла и отправки на сервер. Клиентские процедуры явно отделяются от серверных; объектная модель на клиенте ограничена. На клиенте нельзя работать с БД, прикладными объектами (`СправочникОбъект.<имя>`) и запросами.

- Источник: [Клиент-серверный вариант работы](https://v8.1c.ru/platforma/klient-servernyy-variant-raboty/), «Выполнение основной функциональности на сервере», «Использование встроенного языка на клиенте».

## Общие формы

Общие экранные формы не принадлежат конкретному объекту, относятся к конфигурации в целом.

- Источник: [Объекты конфигурации 1С:Предприятия 8](https://its.1c.ru/db/content/metod8dev/src/platform81/startersdev/i8102579.htm), «Общие формы».
