# Объекты конфигурации (обзор)

## Назначение

Структура прикладного решения (конфигурации) определяется составом объектов конфигурации и связями между ними. Объекты конфигурации — средства «1С:Предприятия» для отражения объектов и явлений предметной области (например, справочник «Контрагенты», документ «Счет»). Можно создавать объекты без явного физического воплощения (регистры сведений, обработки и т. д.).

На этапе создания конфигурации разработчик создаёт объекты, настраивает свойства и связи, конструирует формы и макеты, пишет модули в определённых точках конфигурации.

- Источник: [Объекты конфигурации 1С:Предприятия 8](https://its.1c.ru/db/content/metod8dev/src/platform81/startersdev/i8102579.htm) (методическая поддержка разработчиков). Проверено публично, 2026-09-16.

Оглавление гл. 1 руководства 8.3.26 содержит разделы: понятие «конфигурация», объект конфигурации, свойства, основные виды, подчинённые группы, типизированные и типообразующие объекты, командный интерфейс, форма, модуль, макет.

- Источник: [Глава 1. Концепция системы](https://its.1c.ru/db/v8326doc/bookmark/dev/TI000000013), п. 1.3. Оглавление проверено; определения в теле главы — **не проверено / за подпиской**.

## Блоки взаимосвязи (общая схема)

1. **Условно-постоянная информация** — данные, меняющиеся сравнительно редко (константы, справочники, перечисления).
2. **Документы** — регистрация событий и операций; журналы как смысловая группировка. Документ характеризуется номером и датой. Служебные объекты: **Нумераторы** (сквозная нумерация разных видов), **Последовательность** (порядок проведения / корректность движений).
3. **Регистры** — состояния и количества; могут храниться и плановые данные.
4. **Обработка и вывод** — обработки (действия над данными) и отчёты (представление/печать). Отчёты и обработки не сохраняются в БД как прикладные данные объекта; реквизиты и табличные части у них — для параметров формирования.

- Источник: [Объекты конфигурации 1С:Предприятия 8](https://its.1c.ru/db/content/metod8dev/src/platform81/startersdev/i8102579.htm), разделы «Взаимосвязь объектов», «Объекты конфигурации».

## Прикладные виды (кроме ветви «Общие»)

По той же методической статье (платформа 8):

| Вид | Суть по источнику |
|-----|-------------------|
| Константы | Редко изменяемые значения; обычно примитивный, ссылочный или составной тип |
| Справочники | Условно-постоянные списки; обычно код и наименование; реквизиты и табличные части |
| Документы | События и хозяйственные операции; номер и дата; проведение может менять регистры |
| Журналы документов | Группировка документов **разных** видов; для одного вида достаточно формы списка |
| Нумераторы | Сквозная нумерация нескольких видов документов |
| Последовательности | Хронологический порядок; контроль актуальности итогов; в 8 могут быть измерения |
| Перечисления | Набор значений на этапе разработки, не редактируется в режиме Предприятие |
| Отчёты / обработки | Не сохраняются в БД; реквизиты — параметры |
| Планы видов характеристик | Доп. характеристики; новые свойства можно вводить в режиме Предприятие; механизм субконто |
| Регистры сведений / накопления | См. [registers.md](registers.md) |
| Планы счетов | Список счетов; проводки хранятся в регистрах бухгалтерии |
| Регистры бухгалтерии | Записи (проводки) на одном плане счетов; один план счетов может использоваться в разных регистрах |
| Планы видов расчёта / регистры расчёта | Виды расчёта и записи периодических расчётов |

- Источник: там же.

Состав глав объектов в актуальном руководстве 8.3.26 (оглавление гл. 5): свойства конфигурации; модули управляемого приложения, внешнего соединения, сеанса; ветвь «Общие»; общие свойства объектов; константы; справочники; документы (проведение, нумераторы, последовательности, ввод на основании); журналы; перечисления; отчёты и обработки; планы видов характеристик; регистры.

- Источник: [Глава 5. Объекты конфигурации](https://its.1c.ru/db/v8326doc/bookmark/dev/TI000000167). Оглавление проверено; свойства и алгоритмы в теле — **не проверено / за подпиской**.

## Ветвь «Общие» (по методической статье)

Подсистемы (группировка; объект может входить в несколько; вложенность); общие модули; роли; критерии отбора; интерфейсы; общие формы; общие макеты; общие картинки; стили; языки.

- Источник: [Объекты конфигурации 1С:Предприятия 8](https://its.1c.ru/db/content/metod8dev/src/platform81/startersdev/i8102579.htm), «Общие объекты».

Оглавление 8.3.26 (п. 5.5) дополнительно перечисляет (имена разделов, без раскрытия тела): параметры сеанса; роли и права; общие реквизиты; планы обмена; подписки на события; регламентные задания; функциональные опции; определяемые типы; хранилища настроек; общие команды и группы команд; XDTO-пакеты; Web-сервисы; HTTP-сервисы; WS-ссылки.

- Источник: [Глава 5. Объекты конфигурации](https://its.1c.ru/db/v8326doc/bookmark/dev/TI000000167), п. 5.5. Тело — **не проверено / за подпиской**.

## Отличия, явно указанные в методической статье (8 vs 7.7)

- У справочников и документов могут быть **несколько табличных частей**.
- Периодических реквизитов справочников в версии 8 нет; история — через периодические регистры сведений.
- У пользователя может быть **несколько ролей**.
- У последовательностей могут быть измерения.
- Виды расчёта хранятся в планах видов расчёта как объекты данных (в т.ч. ввод в режиме Предприятие).
- Регистры бухгалтерии: возможны без поддержки корреспонденции; измерения и ресурсы задаёт разработчик.

- Источник: [Объекты конфигурации 1С:Предприятия 8](https://its.1c.ru/db/content/metod8dev/src/platform81/startersdev/i8102579.htm).
