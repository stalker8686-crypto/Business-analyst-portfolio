## Внешняя обработка

Обработка — программа на языке 1С. Внутренняя — в дереве конфигурации, раздел «Обработки». Внешняя — файл **`.epf`**, запуск **Файл | Открыть**. Создание: **Файл | Новый** → «Внешняя обработка». Могут быть реквизиты, формы, макеты. Имя объекта **без пробелов**, регистр не различается. **Синоним** — представление для пользователя; в коде — **имя**. **Комментарий** — доп. сведения. Форма: конструктор, тип **обычная или управляемая**. Вкладки формы в пособии: **Диалог**, **Модуль**, реквизиты. Кнопка **Выполнить** вызывает обработчик в модуле формы.

После правки в конфигураторе: сохранить; в режиме «1С:Предприятие» **закрыть и открыть обработку снова** (уже открытая — старая версия).

## Модули (добавки к [modules.md](modules.md))

Контексты: **глобальный** (константы, перечисления, регистры и др. метаданные, системные процедуры, экспорт общих модулей) и **локальный** модуля.

Типы, названные в пособии сверх уже зафиксированных в паке:

- **модуль объекта** — общие события объекта (для документа: запись, проведение, отмена проведения); у внешней обработки — «Действия → Открыть модуль объекта»;
- **модуль приложения** — запуск/завершение; **обычного** (толстый клиент) и **управляемого** (веб, тонкий, толстый в управляемом режиме) — контекстное меню корня конфигурации;
- **модуль сеанса** — единственная процедура **`УстановкаПараметровСеанса()`**;
- **модуль внешнего соединения** — как модуль приложения, режим COM;
- **модуль менеджера объекта** — переопределение стандартного события выбора при **вводе по строке**;
- **модуль команды** — предопределённая **`ОбработкаКоманды()`**.

Три части модуля: описание переменных (`Перем` до первой процедуры/функции/исполняемого оператора) → процедуры/функции → **раздел основной программы** (исполняемые операторы вне процедур, при запуске модуля). В **общих модулях** разделы переменных и основной программы **отсутствуют** (совпадает с методической статьей в паке).

Пособие пишет ключ **`Экспорт`** у `Перем` / `Процедура` / `Функция` «только в глобальном модуле» (меню «Действия | Глобальный модуль»). Это формулировка пособия, не проверена по ITS 8.3.26.

## Литералы и базовые типы (пособие)

- Число: дробь через **точку** (`5.25`).
- Строка: **двойные кавычки**.
- Дата: **одинарные кавычки**, `'20120310'` или `'20120310195900'`.
- Булево: `Истина` / `Ложь` (в пособии: в числовом представлении 1 и 0).
- Пустое значение: «не определено» (в тексте раздела типов).

Агрегатные: объекты дерева + коллекции + `ТекстовыйДокумент` / `ТабличныйДокумент`. Пример менеджера: `Товары = Справочники.Номенклатура`; методы через `.` — **`НайтиПоНаименованию`**, **`НайтиПоКоду`**, сравнение с **`ПустаяСсылка()`**. Неопределённые агрегатные (`Справочник`, `Документ`…) vs конкретизированные (`Справочники.Номенклатура`). Пособие: типов «Отчет»/«Обработка» как данных нет.

Точка с запятой — конец строки; обычно **не** ставят у `Процедура`/`КонецПроцедуры`, `Функция`/`КонецФункции`, начала цикла и `Если...Тогда`. Комментарий: **`//`** до конца строки (кнопки «Добавить/Удалить комментарий»).

## Процедуры, функции, операции

```
Процедура Имя(Параметр1, ...) [Экспорт]
    ...
КонецПроцедуры

Функция Имя(Параметр1, ...) [Экспорт]
    Возврат [Значение];
КонецФункции
```

Скобки у вызова — даже без параметров. Процедуру можно прервать **`Возврат`**; функция **обязана** заканчиваться `Возврат`. `Процедура`/`КонецПроцедуры` и `Функция`/`КонецФункции` — «операторные скобки», без `;`.

Арифметика: `+ - * / %` (остаток), унарный минус. **Дата + число**: к дате без времени (0:00:00) прибавляются **секунды** (пример `'20120310' + 5` → 10.03.2012 0:00:05). Конкатенация строк `+` (не-строка приводится к строке). Сравнение: `>` `>=` `<` `<>` (в HTML таблицы знак «меньше или равно» обрезан). Булевы: **`И` `ИЛИ` `НЕ`**. Присваивание `=`.

Условие:

```
Если ... Тогда
ИначеЕсли ... Тогда
Иначе
КонецЕсли;
```

Оператор **`?`** — в оглавлении гл. 5.1; тело примеров в HTML сильно смешано с `Если` — сигнатуру `?` из пособия **не восстанавливать**.

Циклы (не путать с «1С:Элемент»: там `для`/`пока` без `Цикл`/`КонецЦикла`):

```
Для Имя = Выражение1 По Выражение2
Цикл
    [Продолжить;] [Прервать;]
КонецЦикла;

Для каждого Переменная из КоллекцияЗначений
Цикл
КонецЦикла;

Пока Выражение Цикл
КонецЦикла;
```

`Для`: пока счётчик от Выражение1 до Выражение2 включительно (формулировка пособия). `Пока`: пока выражение **Истина**; счётчик вручную.

## Диалог (имена из пособия)

- `ВвестиЗначение(Значение, Подсказка, Тип);` — тип через `Тип("Число")` или `Тип("ДокументСсылка.ПоступлениеТоваровУслуг")`.
- `ВвестиЧисло(Значение [, Подсказка][, Длина][, Точность]);`
- Заголовок **ВвестиСтроку**; в блоке синтаксиса HTML написано `ВведитеСтроку (Значение [, Подсказка] [, Длина] [, Многострочьность]);`
- `ВвестиДату` / в синтаксисе HTML `ВведитеДату`; параметр `ЧастиДаты.ДатаВремя` (в одном месте опечатка `ЧастьДаты.Время`).
- `Вопрос(ТекстВопроса, Кнопки [, Таймаут][, КнопкаПоУмолчанию] [, Заголовок][, КнопкаТаймаута]);` примеры: `РежимДиалогаВопрос.ДаНет`, `КодВозвратаДиалога.Да` / `.Нет`. Таблица 1.3 в HTML обрезана. Предложение «диапазон дат» у `Вопрос` в том же абзаце — так в тексте, семантика кнопок — из примеров.
- `Предупреждение(ТекстСообщения [, Таймаут] [, Заголовок]);`
- `Сообщить(ТекстСообщения);` — «табло» внизу экрана.

## Функции данных (список имён из пособия)

Число: **`Цел`**, **`Окр`**. Строка: **`СтрДлина`**, **`СокрЛП`**. Дата: **`ТекущаяДата`**, **`ДобавитьМесяц`**, **`ДеньНедели`**, **`Год`**, **`Месяц`**, **`День`**, **`Час`**, **`Минута`**, **`Секунда`**, **`НачалоГода`/`Квартала`/`Месяца`/`Недели`/`Дня`/`Часа`/`Минуты`**, **`Конец…`** тех же периодов. Преобразование: **`Число(значение)`**, **`Строка(значение)`**, **`Дата(...)`**. **`Формат(Значение [, ФорматнаяСтрока])`** — в примерах `ЧЦ`, `ЧДЦ`, `ЧГ=0`, `ЧРГ`, `ДФ=`. **`Мин`**, **`Макс`**.

Сигнатуры параметров, кроме явно выписанных выше, в выжимку не достраивались.

## Массив, список значений, таблица значений

Массив: `Новый Массив()` (в примерах HTML слитно `НовыйМассив`). Индекс с **0**. Методы в заголовках: **`Добавить`**, **`Вставить`**, **`Количество`**, **`Найти`**, **`Удалить`**, **`Очистить`**, **`ВГраница`**.

Список значений: не в БД; `Новый СписокЗначений`; **`Добавить([Значение][, Представление][, Пометка][, Картинка])`**, **`Вставить`**, **`Количество`**, **`Удалить`**, **`Очистить`**, **`НайтиПоЗначению`**, **`СортироватьПоЗначению(НаправлениеСортировки.Возр|Убыв)`**, **`ВыбратьЭлемент`**.

Таблица значений: **`Колонки.Добавить`**, строки **`Добавить`**, **`Свернуть`**, **`Итог(Колонка)`** (сумма числовой колонки).
