## Чего в паке нет (явные пробелы из файлов)

Зафиксировано в самих выжимках и в `sources/`, не дописано догадками:

- **Тела глав «Руководства разработчика» 8.3.26 на ITS** — публично открывались оглавления (гл. 1, 4, 5, 7, 8, 11, 12, 13, 30 и др.); полный текст — «не проверено / за подпиской». В том числе: свойства объектов; оперативное/неоперативное проведение, момент времени, оперативная отметка; нумерация 5.6.6; контексты общих модулей; безопасный режим; язык RLS 5.5.4.8.2; состав формы (свойства элементов, динамический список); поведение аннотаций расширения **Перед / После / Вместо / ИзменениеИКонтроль**; ограничения расширений п. 30.1.3; права в расширениях; сигнатуры функций языка запросов из оглавления гл. 8.
- **Гл. 15–17** (обмен, форматы, интеграции в руководстве) — только упоминание во введении / оглавлении.
- **База ITS** `https://its.1c.ru/db/v8326doc` и корневой `https://its.1c.ru/db/edtdoc` — заголовок без полного тела базы. Отдельные HTML `edtdoc` (CLI, написание кода и др.) открывались публично.
- **Полный синтакс-помощник / «Описание встроенного языка»** как HTML объектной модели — не найден. Есть описание **инструмента** на v8.1c.ru.
- **Глоссарий** `its.1c.ru/db/v8devgloss` и **стандарты** `its.1c.ru/db/v8std` — указаны во введении, не проверялись.
- **users.v8.1c.ru** — закрытый доступ, не проверялся.
- **1cedt.dev** / **www.1cedt.dev** — HTTP 500. **help.edt.1c.ru** — DNS не резолвится.
- **Агрегаты** регистра накопления — на v8.1c.ru только отсылка «Подробнее…».
- **API параметров сеанса** и семантика большинства команд **1C:EDT CLI** (кроме перечисленных в `edt.md`) не раскрыты.
- Прикладные учётные процессы (склад, зарплата, продажи как BPMN) в паке **не описаны** — только механизмы платформы. Маршрут объекта «бизнес-процессы» на уровне платформы — в [business-processes.md](business-processes.md) и в [processes.md](processes.md).
- **Полные тела** разделов 1cmycloud «Идиомы», глоссарий, «Новое в 9.1», стандартная библиотека, сравнение с Python, IDE Скрипта — не копировались (корни открыты, см. [sources/1cmycloud.md](../sources/1cmycloud.md)). Язык «1С:Элемент» не подменяет синтакс-помощник ITS.
- Учебное пособие Фёдоровой — только **дельта** в [textbook-1c-programming.md](textbook-1c-programming.md); не канон ITS. Оператор `?` в том HTML без надёжной сигнатуры — не восстановлен (сигнатура `?` есть в PDF Дадяна, тоже не ITS).
- PDF ATU 48747 (Дадян) — только **дельта** в [atu-library-48747.md](atu-library-48747.md); OCR, не канон ITS. Не смешивать с «1С:Элемент».
