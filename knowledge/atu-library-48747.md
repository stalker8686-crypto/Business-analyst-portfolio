## Правила кода и типы (юниты 2–6) — добавки

- Команда = имя + параметры в скобках + `;`; одна команда может занимать несколько строк; команды можно писать в одну строку, если есть `;`.
- `Сообщить` принимает не только строку, «данные любого другого типа».
- К дате «можно прибавлять и отнимать секунды»; сутки как `60 * 60 * 24`.
- Педагогика `+` в пособии: тип результата берётся **с левого** операнда (`"123"+ 456` → строка `"123456"`; `100 + "001"` → число `101`, потому что `"001"` «переводится в число 1»). Это формулировка пособия, не сверка с ITS.
- Имя: буквы русского и английского алфавитов, цифры, подчёркивание; **не** с цифры; в тесте запрещены кавычки, пробел, угловые скобки; имена `_НазваниеНашейПланеты` и с цифрой **не в начале** — допустимы.
- Логическое: `Истина`/`Ложь`; сравнения `=` `<>` `>` `<` `>=` `<=`. Вывод логического через `Сообщить` в примерах: **«Да»** / **«Нет»**.
- Таблица операции **И** (верно «тогда и только тогда, когда верны оба»).

## Условие, `?`, циклы (юниты 7–10)

Расширенная форма с `Иначе` и `ИначеЕсли` уже есть в паке. **Тернарная команда** в пособии (юнит 7; у Фёдоровой сигнатура не восстанавливалась):

```
?(<Логическое выражение >, <выражение 1 >, <выражение 2 >);
```

Смысл по тексту: вычислить логическое; при «Истина» — выражение 1, иначе — выражение 2.

Цикл `Для Имя = НачальноеЧисло По КонечноеЧисло`: шаг +1; тело, пока текущее не стало **больше** конечного. Если начальное **уже больше** конечного — **ни разу**. Если равны — **один раз**. `Пока Истина` / `Пока 1 = 1` в пособии названы **бесконечными**. Вложенные `Для` (произведение числа шагов).

## Массив и структура (юниты 11–12, разд. 2)

- `Новый Массив(N)` — сразу N «ящиков», индексы **0 … N−1**. `Новый Массив` без числа — пустой; обращение к `[0]` **до** `Добавить` — ошибка (формулировка пособия).
- Структура: `Новый Структура("Фамилия, Имя, Отчество")` затем поля через `.`; ключ — имя, не индекс. В разд. 2: ключ **только строковый** и «должен удовлетворять требованиям к именованию переменных»; методы **`Вставить`**, **`Количество`**, **`Очистить`**, **`Свойство(<Ключ>, <НайденноеЗначение>)`** (Истина/Ложь — найден ли ключ), **`Удалить`**. Конструктор `Новый Структура("Часы,Минуты,Секунды", 12, 45, 33)`.
- Разд. 2, массив: методы **`ВГраница`**, **`Вставить`**, **`Найти`** (индекс или **Неопределено**), **`Получить`/`Установить`** «как `[]`»; конструктор нескольких чисел — «массивы массивов» (аналог многомерного); **«массив ВСЕГДА передаётся в функцию ПО ССЫЛКЕ»**; `Новый ФиксированныйМассив(Числа)` — нельзя менять/добавлять/удалять элементы (формулировка пособия).
- Обход: `Для Каждого … Из … Цикл` (в OCR разд. 2 также «Дня каждого»).

## Функции, `Экспорт`, параметры (юниты 13–14, разд. 2 юнит 4)

Функция **обязана** вернуть результат (`Возврат`); процедура «не содержит выходного отверстия». В примерах экспорт в **общем модуле** с именем **`Уроки`**: вызов `Уроки.ПлошадьКруга(...)` из модуля управляемого приложения (орфография имени функции — как в OCR).

Разд. 2: **`Экспорт`** у процедуры означает доступность «из всех других программных модулей», если слово стоит в модуле **обычного приложения**, **управляемого приложения** или **общем** модуле. Это **другая** формулировка, чем у Фёдоровой («только в глобальном модуле») — обе как тексты пособий, без выбора канона ITS.

- Передача **по ссылке** (изменение видно снаружи) vs **`Знач`** «по значению» — «возможно только для простых типов (число, строка, дата,…)».
- Значения параметров по умолчанию: `Процедура П5(Имя = "Сергей", Фамилия, Отчество = "не задано")`; вызов с пропуском аргументов в примерах `П5(, "Иванович")`, `П5(,,)`.
- Локальные `Перем` «в самом начале» тела процедуры. Неявный `Возврат` в конце процедуры, если явного не было.

## Даты (юнит 17 и разд. 2 юнит 1)

Способы значения: литерал `'20140601'`; конструктор **`Дата(2014, 06, 01)`**; **`ВвестиДату`** после начального `'00010101'`; **`ТекущаяДата()`**. Функции сверх уже названных в паке Фёдоровой: **`ДеньГода`**, **`НеделяГода`**. **`ДеньНедели`**: число **1…7**, **1 = понедельник**. Разность двух дат — **секунды**. **`ДобавитьМесяц(дата, N)`**, отрицательный N — вычитание месяцев.

Разд. 2 описание типа: григорианский календарь **с 01 января 0001**, время «с точностью до **0,1 миллисекунды**». Литерал `'ГГГГММДДччммсс'`; год/месяц/день обязательны; хвост можно опускать (время 0, для даты — единица); «допускается использование различных разделителей». Пустой отсчёт: `'00010101'`. Также `Дата("20130724")` в примере.

## Диалог — добавка

Помимо уже зафиксированных имён: **`ОткрытьЗначение(...)`** (показ значения пользователю). Перед первым `ВвестиЧисло(Имя)` пособие требует инициализации имени (пример: `ЧислоА = 0`).
