# Бухгалтерский учёт (механизм платформы)

Публичное описание механизма — на v8.1c.ru. Тело гл. 11 «Руководства разработчика» 8.3.26 на ITS — **оглавление / за подпиской** (2026-09-18).

## Назначение

Механизм бухгалтерского учёта реализует систему **двойной записи**. Принципы учёта конкретной страны разработчику не навязываются: можно строить модели и для России, и для других стран.

Возможности, перечисленные на v8.1c.ru:

- многоуровневые планы счетов с произвольной иерархией; фиксированная или переменная разрядность кодов;
- аналитический учёт в нескольких разрезах и уровнях;
- учёт одновременно по нескольким планам счетов;
- консолидированный учёт по нескольким юридическим лицам;
- для отдельных разрезов аналитики — произвольное число видов учёта (количественный, суммовой, валютный и т. д.).

Три объекта конфигурации: **План счетов**, **План видов характеристик**, **Регистр бухгалтерии**.

- Источник: [Бухгалтерский учет](https://v8.1c.ru/platforma/buhgalterskiy-uchet/). Проверено публично, 2026-09-18.

Оглавление гл. 11 (8.3.26): обзор; планы счетов; аналитический учёт; виды учёта; записи и наборы записей; консолидированный учёт; создание плана счетов (свойства, виды учёта, предопределённые счета); регистры бухгалтерии (свойства, записи). Тело — **не проверено / за подпиской**.

- Источник: [Глава 11. Бухгалтерский учет](https://its.1c.ru/db/v8326doc/bookmark/dev/TI000000641).

## План счетов

Описывает синтетические счета для группировки хозяйственной деятельности. В прикладном решении может быть любое число планов счетов.

Иерархия «счёт — субсчета»: число уровней вложенности субсчетов **не ограничено**. Счета создаёт разработчик (предопределённые) или пользователь; **пользователь не может удалять счета разработчика**.

Аналитика: счёту/субсчёту ставят в соответствие субконто. Для этого план счетов связывается с **планом видов характеристик** (виды субконто). У счёта — признаки учёта (например количественный и валютный); у субконто — свои признаки (суммовой, количественный, валютный). Реквизиты счёта могут хранить доп. сведения (пример: запрет использовать счёт в проводках).

Формы: список, счёт, выбора (автогенерация или свои).

- Источник: [План счетов](https://v8.1c.ru/platforma/plan-schetov/).

## План видов характеристик (в т.ч. субконто)

Хранит характеристики объектов: пользователь задаёт характеристику, тип значения и значения. Структура похожа на справочник (реквизиты, ТЧ, иерархия, предопределённые). Главное отличие: у каждой характеристики хранится **тип значения**. Перечень допустимых типов задаёт разработчик; пользователь выбирает тип из перечня. Для типов, которых нет в решении, разработчик может указать специальный пустой справочник дополнительных значений характеристик.

Формы как у справочника: список, характеристика, группа, выбор, выбор группы.

- Источник: [План видов характеристик](https://v8.1c.ru/platforma/plan-vidov-harakteristik/).

В механизме бухучёта план видов характеристик описывает виды субконто и типы их значений.

- Источник: [Бухгалтерский учет](https://v8.1c.ru/platforma/buhgalterskiy-uchet/).

## Регистр бухгалтерии

Связан с **одним** планом счетов; хранит итоги по его структуре. Структура записи строится динамически от настроек плана счетов. С корреспонденцией — двойная запись, поля **СчетДт** и **СчетКт**; без — одно поле **Счет**. Запись связана с регистратором, номером строки, периодом. Уникальность: не две записи одной строки одного документа.

- Источник: [Регистр бухгалтерии](https://v8.1c.ru/platforma/registr-buhgalterii/); также [registers.md](registers.md).

## Что по-прежнему закрыто

Свойства плана счетов и регистра из гл. 11.7–11.8, алгоритмы консолидации, полный API остатков/оборотов с субконто — ITS, не выгружались. Не описывать проводки типовой «1С:Бухгалтерии» как требования платформы.
