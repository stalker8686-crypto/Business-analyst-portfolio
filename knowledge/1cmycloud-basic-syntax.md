# Базовый синтаксис языка «1С:Элемент» (справка 1cmycloud)

Это **не** встроенный язык платформы «1С:Предприятие 8» и не синтакс-помощник ITS. Источник: публичная справка `1cmycloud.com/console/help/lang/docs/` (версия в шапке: **9.1**). Дата обращения: **2026-09-18**. Все перечисленные ниже URL открылись как HTML, HTTP 200.

## Что это за язык

Язык «1С:Элемент» — кросс-платформенный язык высокого уровня со **статической типизацией**, стандартной библиотекой и поддержкой функционального программирования. Программа строится из переменных, свойств/методов экземпляров, коллекций, операций, инструкций и методов.

Инструкции могут объединяться в блоки: начинаются ключевым словом (`попытка`, `выбор`, `если` и т. д.) и заканчиваются символом **`;`**. Объявления методов, исключений, структур и перечислений тоже заканчиваются **`;`**.

- Источник: [Язык «1С:Элемент»](https://1cmycloud.com/console/help/lang/docs/topics/1c-element-language-overview/).

Точка входа учебного примера — метод **`Скрипт()`**.

- Источник: там же; также [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/).

## Комментарии

Однострочные: `// …`. Многострочные (блочные): `/* … */`. Компилятор их игнорирует.

- Источник: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Комментарии».

## Консоль: вывод и ввод

Вывод в стандартный поток: **`Консоль.Записать()`**.

Управляющие последовательности в строковых литералах начинаются с `\`:

| Последовательность | Смысл по справке |
|--------------------|------------------|
| `\н` | новая строка |
| `\в` | возврат каретки |
| `\т` | табуляция |
| `\\` | обратная косая черта |
| `\"` | двойные кавычки |
| `\%` | символ `%` |
| `\$` | символ `$` |
| `\юХXХХХ` | произвольный символ Unicode; код — **десятичное** число |

`\%` и `\$` — экранирование интерполяции. Последовательности `%x` и `$x`, где `x` не буква и не `{`, экранировать не нужно.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Вывод…»; [Управляющие последовательности](https://1cmycloud.com/console/help/lang/docs/topics/escape-sequence/).

Методы ввода типа `Консоль` с префиксом **`Считать`**: `СчитатьСимвол()`, `СчитатьСтроку()`, `СчитатьЧисло()` (формат — локаль консоли), `СчитатьБулево()` (ввод `Истина` / `Ложь` / `True` / `False`, учитывается регистр), `СчитатьПароль()` (тип `Строка`, символы в консоль не выводятся). Параметр **`ПодсказкаВвода`** — строка в начале ввода.

- Источник: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Чтение…»; подробнее тип: [Консоль](https://1cmycloud.com/console/help/lang/docs/topics/system-console/).

## Переменные и константы

Объявление **внутри тела метода** модификаторами:

- **`пер`** — чтение и запись (`var`);
- **`знч`** — только чтение (`val`);
- **`исп`** — только чтение (`use`); тип — потомок **`Закрываемое`**; при выходе из области видимости вызывается **`Закрыть()`**.

**`конст`** (`const`) — именованное значение, нельзя менять; объявляется **на уровне модуля** (вне тела метода); значение инициализации **вычислимо при компиляции**.

Переменную можно использовать **только после инициализации**. Тип выводится из инициализации; без инициализации тип **нужно указать**. Если выражения нет — значение по умолчанию типа; иначе ошибка компиляции инициализации (если нет умолчания и в составном типе нет `Неопределено`). Тип `неизвестно` или тип с `Неопределено` инициализируется **`Неопределено`**.

Способы: `модификатор имя: тип`; `модификатор имя = выражение`; составной тип через `|`.

Для `конст` вычислимы: литералы (в т.ч. коллекций); обращения к константам модулей; операции над вычислимыми, **кроме** вызовов методов и свойств, конструкторов, сложения `Строка` с другим типом.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Переменные»; [Инструкция объявления переменной](https://1cmycloud.com/console/help/lang/docs/topics/variable-declaration-statement/).

Тип отделяется двоеточием **без пробела перед `:`**, с пробелом после. У `|` в составном типе пробел не ставится (`Строка|Число|Булево`).

`Неопределено` в списке типов явно не пишут: суффикс **`?`**. Два типа: слитно (`Строка?`). Больше двух: `|?` в конце (`Строка|Число|?`), не `Строка|Число?`.

Соглашение: не указывать тип явно при инициализации литералом или конструктором.

- Источник: [Описание типа и инициализация](https://1cmycloud.com/console/help/lang/docs/topics/type-description-and-initialization/).

## Строковые шаблоны

Интерполяция: **`$имя`** — простая переменная; **`${выражение}`** — выражение; **`%имя`** — форматированный вывод.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Строковые шаблоны»; [Интерполяция строк](https://1cmycloud.com/console/help/lang/docs/topics/string-interpolation/).

## Методы

Ключевое слово **`метод`**. Параметры и возврат с типами через `:`. **`возврат`** возвращает значение. Методы принадлежат типам или объявляются самостоятельно.

Ключевое слово **`ничто`** (`void`) — тип возвращаемого значения, если метод ничего не возвращает. Семантику не меняет; равносильно отсутствию типа возврата. **Никуда не присваивается** и не используется иначе как тип возврата метода. В **функциональных типах**, если ничего не возвращается, `ничто` **обязателен**. Значение `(T1,…,Tn) -> R` можно присвоить в `(T1,…,Tn) -> ничто`.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Методы»; [Ключевое слово «ничто»](https://1cmycloud.com/console/help/lang/docs/topics/void-keyword/); [Методы](https://1cmycloud.com/console/help/lang/docs/topics/methods-in-built-in-script-language/).

## Импорт скриптов

Директива **`#требуется`**: подключение внешних скриптов. Все зависимости — **в начале файла до любого исполняемого кода**. Пути относительные или абсолютные. Расширение в примерах: **`.sbsl`**.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Импорт»; [Модульная разработка](https://1cmycloud.com/console/help/lang/docs/topics/modular-programming-in-1c-script/).

## Условие `если`

Только **логическое** выражение → `Истина` / `Ложь`. Синтаксис (со страницы инструкции):

```
если логическое-выражение
    инструкции-языка
[иначе[если логическое-выражение]
    инструкции-языка]
;
```

Вложенность любая. **Безусловного перехода в языке нет.**

Логические операторы: **`или` / `и` / `не`**. Тернарный: **`логическое-выражение ? выражение-если-истина : выражение-если-ложь`**. Всегда возвращает результат; оба выражения совместимы с целевым типом; методы без возврата использовать нельзя.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Условная инструкция»; [Инструкция «если»](https://1cmycloud.com/console/help/lang/docs/topics/if-statement/); [Логические и булевы операции](https://1cmycloud.com/console/help/lang/docs/topics/logical-and-boolean-operations/); [Тернарная операция «?»](https://1cmycloud.com/console/help/lang/docs/topics/question-mark-operation/).

## Циклы

**`для из`**: обход потомков **`Обходимое`** и значений **`Строка`**. Переменная элемента — **`знч`**, присваивать ей нельзя. Завершение — когда обработаны все элементы (порядок может меняться, если не определён).

**`для по`**: счётчик типа **`Число`**, модификатор **`знч`**, область — тело цикла, нельзя объявить вне цикла.

```
для счетчик-цикла = выражение1 [вниз] по выражение2 [шаг N]
    тело-цикла
;
```

`выражение2` и шаг вычисляются **один раз** в начале. Если начальное значение **строго больше** конечного (без `вниз`) — тело не выполняется. Без `шаг` изменение на **1**. **`вниз`** — обратный обход. **`продолжить`** — следующая итерация; **`прервать`** — выход из цикла.

**`пока`**: условие проверяется **до** тела; пока `Истина`.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/); [Цикл «для из»](https://1cmycloud.com/console/help/lang/docs/topics/for-in-loop/); [Цикл «для по»](https://1cmycloud.com/console/help/lang/docs/topics/for-loop/); [Цикл «пока»](https://1cmycloud.com/console/help/lang/docs/topics/while-loop/).

## Инструкция `выбор`

Альтернатива цепочке `если`. Две формы: **полная** (есть выражение выбора) и **предикатная** (без него). Ветки **`когда`**, необязательный **`иначе`**, конец **`;`**. В полной форме условие: `выражение-выбора == выражение-сравнения`. Несколько значений через запятую (`когда 12, 1, 2`).

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Инструкция „выбор“»; [Инструкция «выбор»](https://1cmycloud.com/console/help/lang/docs/topics/case-statement/).

## Области видимости

Ограничиваются: **`область`**, телом метода, циклами, границами скрипта (аннотации видимости). Переменные цикла и ветки `если` снаружи недоступны.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Области видимости»; [Область видимости имен](https://1cmycloud.com/console/help/lang/docs/topics/name-scope/).

## Коллекции, структуры, перечисления

Коллекция — набор значений (одного или разных типов). Обход `для из`. Лямбды в примерах: **`Фильтровать`**, **`СортироватьПо`**, **`Преобразовать`**. Методы из примеров: `Пусто()`, `Содержит()`, `Сортировать()`, `Размер()`, `Сумма()`, индексация `[i]`. Синтаксис массива: `[…]`; типизированный литерал: `<Число>[1, 2]`.

**`структура`**: поля (в примере `обз знч`), методы экземпляра; создание **`новый Имя(…)`**.

**`перечисление`**: именованные константы; **`умолчание`** — значение по умолчанию.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/); [Коллекции](https://1cmycloud.com/console/help/lang/docs/topics/collections/); [Структура](https://1cmycloud.com/console/help/lang/docs/topics/structure/); [Перечисление](https://1cmycloud.com/console/help/lang/docs/topics/enumeration-type/).

## `новый`

Создание экземпляров типов с конструкторами: `новый ИмяТипа()` или с параметрами. Возможна **перегрузка** конструкторов. Не у всех типов есть конструкторы (пример: тип-одиночка через свойство глобального контекста).

- Источник: [Операция «новый»](https://1cmycloud.com/console/help/lang/docs/topics/new-operator/).

## `Неопределено` и операции `!` / `?.` / `??`

Литерал **`Неопределено`** — единственное значение типа. Переменные типа **`неизвестно`** изначально имеют его. Суффикс `?` = тип плюс `Неопределено`. Вызов методов у составного типа с `Неопределено` на компиляции допускается; в рантайме при фактическом `Неопределено` — **исключение**.

Операции (базовый синтаксис):

- **`!`** — настойчивая операция (гарантия ≠ `Неопределено`);
- **`?.`** — безопасный доступ;
- **`??`** — значение по умолчанию: левое, если не `Неопределено`, иначе правое.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/); [Тип «Неопределено»](https://1cmycloud.com/console/help/lang/docs/topics/undefined-type/); [Операция «??»](https://1cmycloud.com/console/help/lang/docs/topics/double-question-mark-operator/); [Настойчивая операция «!»](https://1cmycloud.com/console/help/lang/docs/topics/exclamation-mark-operation/); [Операция безопасного доступа «?.»](https://1cmycloud.com/console/help/lang/docs/topics/secure-access-operation/).

## `это` и `как`

**`это`**: `что-проверяем это [не] контрольный-список` — список типов через `|`. Результат `Истина`/`Ложь`. После успешной проверки объект можно использовать как целевой тип (в т.ч. параметризованные коллекции).

**`как`**: `выражение как тип`. Если приведение невозможно — **исключение**. **Не преобразует** типы (не `Число`→`Строка`); для преобразования — конструкторы и методы (`новый Число(строка)`, `.ВСтроку()`). Присваивание в `неизвестно` без `как` допустимо.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/); [Операция «это»](https://1cmycloud.com/console/help/lang/docs/topics/is/); [Операция «как»](https://1cmycloud.com/console/help/lang/docs/topics/as/).

## Лямбда-выражения

Синтаксис в примерах: `(А: Число, Б: Число) -> А * Б`. Используются как функциональные типы и аргументы методов коллекций (`Элемент -> …`).

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/); [Лямбда-выражения](https://1cmycloud.com/console/help/lang/docs/topics/lambda-expression/).

## Исключения

Выброс: **`выбросить новый …`**. Обработка: **`попытка` — `поймать` — `вконце`**. У исключения: сообщение, причина, стек. Можно объявлять **`исключение`** (пользовательский тип). Стандартный пример: **`ИсключениеИндексВнеГраниц`**. Блок `вконце` выполняется **в любом случае**.

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Исключения»; [Исключения](https://1cmycloud.com/console/help/lang/docs/topics/exceptions/).

## Аннотации

Пишутся **`@ИмяАннотации`** перед объявлением. В примерах базового синтаксиса:

- **`@Глобально`** — константа видна в других скриптах (после `#требуется`);
- **`@Локально`** — на методах в потребляющем скрипте;
- **`@ПроверятьИспользованиеЗначения`** — не использовать возврат метода без присваивания/использования (ошибка компиляции).

- Источники: [Базовый синтаксис](https://1cmycloud.com/console/help/lang/docs/topics/basic-syntax/), «Аннотации»; [Аннотации](https://1cmycloud.com/console/help/lang/docs/topics/annotations/).
