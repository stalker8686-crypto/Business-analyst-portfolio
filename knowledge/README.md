# Knowledge pack: платформа «1С:Предприятие» и 1C:EDT

Сжатые выжимки по официальной документации фирмы «1С» для проекта 1C_AI.

**Канонические источники и дата обращения:** см. [sources/README.md](../sources/README.md). Дата обращения публичных страниц: **2026-09-16**.

**Правило достоверности.** Каждый факт в файлах тем снабжён ссылкой (URL + название раздела). Полный текст «Руководства разработчика» на ИТС часто отдаёт только оглавление; тело таких разделов помечено как **не проверено / за подпиской**. Синтаксис встроенного языка, права и API, которых нет в проверенном тексте, не дописывались.
