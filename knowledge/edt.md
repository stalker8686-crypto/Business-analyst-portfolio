# 1C:EDT

## Назначение

**1C:Enterprise Development Tools (1C:EDT)** — расширяемая среда разработки прикладных решений. Создана на основе Eclipse. Поддерживает ключевые принципы создания прикладных решений на платформе «1С:Предприятие 8». Инструменты автоматизации разработки; расширение функциональности плагинами Eclipse.

Работает на Windows, Linux, macOS. Интегрирована с Git; возможна интеграция с другими VCS.

На дату обращения главная страница предлагала скачать **2026.2.0 (релиз-кандидат)** и ссылки «Новое в версии 2026.2» / «2026.1».

В одной рабочей области можно хранить и разрабатывать несколько конфигураций, расширений, внешних отчётов и обработок. Есть выбор платформы и базы; групповая разработка в Git; управление ИБ и публикациями на веб-серверах из среды; встроенный веб-сервер для отладки; инструмент «Схема данных» (ER-диаграмма); проверка «на лету» при изменении структуры и модулей.

- Источник: [Главная | 1C:Enterprise Development Tools](https://edt.1c.ru/). Проверено публично, 2026-09-16.

Во введении «Руководства разработчика» платформы ссылки: сайт EDT [edt.1c.ru](https://edt.1c.ru/); документация EDT на ИТС [its.1c.ru/db/edtdoc](https://its.1c.ru/db/edtdoc).

- Источник: [Введение :: 8.3.26](https://its.1c.ru/db/content/v8326doc/src/%D1%80%D1%83%D0%BA%D0%BE%D0%B2%D0%BE%D0%B4%D1%81%D1%82%D0%B2%D0%BE%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D0%B0/%D0%B2%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5.htm), «ИТС».

## Групповая разработка в Git

Групповая разработка и версионирование — через внешнюю систему **Git**. 1C:EDT автоматизирует работу с ветками: ветку можно связать со своей информационной базой; при запуске и отладке автоматически выбирается ИБ, связанная с текущей веткой.

- Источник: [Групповая разработка в Git](https://edt.1c.ru/docs/intro/features3.php). Проверено публично.

Публичные пошаговые примеры (не замена руководства):

- импорт проектов из Git, в т.ч. демо [github.com/1C-Company/dt-demo-configuration](https://github.com/1C-Company/dt-demo-configuration) (в примере два проекта: конфигурация и расширение) — [пк1](https://edt.1c.ru/docs/examples/pk1-import-proekta-iz-udalennogo-repozitoriya/);
- «Совместная работа → Сделать проект общим…» — [ур4](https://edt.1c.ru/docs/examples/ur4-podklyuchenie-proekta-k-lokalnomu-repozitoriyu/);
- «Совместная работа → Фиксировать…» — [ур5](https://edt.1c.ru/docs/examples/ur5-kommit-konfiguratsii/);
- «Совместная работа → Отправить в Upstream» — [ур6](https://edt.1c.ru/docs/examples/ur6-otpravka-vetki-v-udalennyy-repozitoriyu/).

## 1C:EDT CLI

Публичная страница ИТС с полным текстом (2026-09-16): [Интерфейс командной строки 1C:EDT (1C:EDT CLI)](https://its.1c.ru/db/content/edtdoc/src/topics/t000608.html).

Зафиксировано в проверенном тексте:

- Не использовать CLI с рабочими областями, созданными версиями EDT младше **2023.1.0**.
- Для CLI нужны права администратора.
- Исполняемые файлы: Windows — `1cedtcli.exe`; Linux, macOS — `1cedtcli` (каталог исполняемых файлов EDT).
- Первый запуск может занять около 25 секунд.
- Режимы: справочный (можно без `-data`); интерактивный (приглашение `1C:EDT>`); одна команда; последовательность из файла.
- Опции (порядок: `-command` последняя; `-vmargs` перед `-command` или последняя, если нет `-command`): `-data` (рабочая область); `-timeout` (секунды; по умолчанию 60 минут); `-vmargs`; `-V`; `-nl` (язык сообщений).
- В тексте названы команды справки/окружения: `cd`, `exit`, `help`, `install-platform-support`, `platform-versions`, `uninstall-platform-support`, `version`.

Полный актуальный список команд зависит от комплектации; в CLI: `help` без параметров. Расширенный список на странице скриптов плагинов (edt.1c.ru/dev) включает в том числе `build`, `import`, `export`, `validate` и др. — это документация Plugin Developer Guide, не полный контракт каждой команды.

- Источники: [t000608.html](https://its.1c.ru/db/content/edtdoc/src/topics/t000608.html); [Скрипты и скриптовый язык 1C:EDT CLI](https://edt.1c.ru/dev/ru/docs/plugins/dev/cli-script/).

Семантика каждой команды CLI (кроме перечисленного) — **не проверено / за подпиской** или уточняется командой `help <имя>` в конкретной версии EDT.
