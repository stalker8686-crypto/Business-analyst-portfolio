# Встроенный язык 1С

## Назначение

Встроенный язык — часть технологической платформы «1С:Предприятия 8». Позволяет описывать собственные алгоритмы прикладного решения. Имеет общие черты с Pascal, Java Script, Basic, но **не является прямым аналогом** ни одного из них.

Большая часть прикладного решения создаётся визуальным конструированием объектов. Язык нужен для поведения, отличного от типового, и собственных алгоритмов обработки данных. Это скриптовый язык бизнес-логики; выполнение модулей **событийно-зависимое**.

- Источник: [Встроенный язык](https://v8.1c.ru/platforma/vstroennyy-yazyk/). Проверено публично, 2026-09-16.

Глава 4 руководства: типы и операторы в **оглавлении** 8.3.26 (NULL, Булево, Дата, Неопределено, Строка, Тип, Число; Процедура, Функция, «Если», циклы «Для» / обход коллекции / «Пока»; исключения; директивы компиляции vs препроцессор; синхронные/асинхронные методы). Тело главы — **не проверено / за подпиской**. Имена пунктов оглавления — не синтаксис операторов.

- Источники: [Введение](https://its.1c.ru/db/content/v8326doc/src/%D1%80%D1%83%D0%BA%D0%BE%D0%B2%D0%BE%D0%B4%D1%81%D1%82%D0%B2%D0%BE%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D0%B0/%D0%B2%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5.htm); [Глава 4](https://its.1c.ru/db/v8326doc/bookmark/dev/TI000000116) (оглавление).

## Синтакс-помощник (инструмент конфигуратора)

Публичного HTML-справочника объектной модели (полный перечень операторов/методов/событий) на its.1c.ru / v8.1c.ru **не найдено**. Официальная страница описывает **инструмент в конфигураторе**, не веб-API.

Зафиксировано на v8.1c.ru:

- дерево: операторы, управляющие конструкции, процедуры и функции, системные константы и др.; ветви — тематические разделы;
- нижняя часть окна: синтаксис, параметры, особенности выбранного элемента; гиперссылки на связанные объекты языка;
- **отбор по контексту исполнения** (пример: только тонкий клиент) — из окна помощника или «Сервис — Параметры — Справка»;
- поиск по началу фразы; полнотекстовый поиск (найденные слова выделяются);
- из модуля: курсор на конструкции → контекстное меню или горячая клавиша → описание; кнопка «Найти текущий элемент в дереве»;
- заготовки методов/функций можно **перетащить мышью** в модуль;
- из палитры свойств — справка только для свойств/методов/событий, **доступных из встроенного языка**;
- в конце описания — ссылка «Методическая информация» (подборка ITS, конференций и др.; не тело синтакс-помощника).

- Источник: [Синтакс-помощник](https://v8.1c.ru/platforma/sintaks-pomoshchnik/). Проверено публично, 2026-09-18. Также [Редактор текста и модуля](https://v8.1c.ru/platforma/redaktor-teksta-i-modulya/) (переход к описанию из модуля).

В 1C:EDT 2025.2 публично названы **Ctrl+F1** (описание с курсора) и **Ctrl+Shift+F1** (открыть синтакс-помощник); дерево типов, закладки, точный и полнотекстовый поиск.

- Источник: [Новое в 1C:EDT 2025.2](https://v8.1c.ru/platforma/news/novoe-v-1c-edt-2025-2/), раздел «Синтакс-помощник».

## Операторы и директивы из публичной документации EDT

Все операторы имеют **русское и английское** написание, допустимо смешивать в одном тексте. Типы прикладных объектов языком не задаются (только визуально). Переменные можно не объявлять; неявное определение — первое присваивание слева; явное — оператор **Перем**.

В модуле формы методы обычно помечают **директивой компиляции**:

- **`&НаСервере`** — процедура есть при исполнении модуля на сервере, на клиенте её нет. Пример из доки EDT: `&НаСервере` + `Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)`.
- **`&НаКлиенте`** — наоборот. Пример: `&НаКлиенте` + `Процедура КомандаОткрыть(Команда)`.

Полный перечень директив гл. 4.8.1.3 — **за подпиской**. Контекст (доступность типов) смотрят в синтакс-помощнике, раздел «Доступность». Примеры из той же страницы EDT: тип **HTTPСервисЗапрос** — «Сервер, толстый клиент»; тип **Массив** — тонкий/веб/мобильный клиент, сервер, толстый клиент, внешнее соединение, мобильное приложение (клиент и сервер).

- Источник: [Написание кода :: 1C:EDT Руководство разработчика](https://its.1c.ru/db/content/edtdoc/src/topics/i248.html). Проверено публично, 2026-09-18.

## Зафиксированные особенности языка

- Предварительная компиляция модулей во внутренний код.
- Кэширование скомпилированных модулей в памяти.
- **Мягкая типизация** — тип переменной определяется типом содержащегося значения и может изменяться.
- Нет программного описания объектов конфигурации: используются встроенные объекты платформы или объекты, созданные визуальным конструированием.

Пример события: **ПередЗаписью** справочника — сразу перед записью элемента в БД.

- Источник: [Встроенный язык](https://v8.1c.ru/platforma/vstroennyy-yazyk/).

## Универсальные коллекции значений

Временные наборы данных на время сеанса:

| Объект | По публичному описанию |
|--------|-------------------------|
| Массив | Пронумерованная коллекция значений произвольного типа; доступ по индексу; элементы могут быть массивами (многомерность) |
| Структура | Пары ключ–значение; ключ **только строковый**; значение произвольное; доступ по имени ключа |
| Соответствие | Пары ключ–значение; ключ практически любого типа |
| СписокЗначений | Динамический набор, в т.ч. для интерфейсных задач; разные типы в одном списке |
| ТаблицаЗначений | Динамическая таблица; разные типы в одной таблице |
| ДеревоЗначений | Как таблица, но строки образуют иерархию; поиск/сортировка/итоги по уровню или с подчинёнными |
| COMSafeArray | Обёртка над многомерным SAFEARRAY из COM |
| ФиксированныйМассив | Неизменяемый массив; заполняется системой при инициализации или разработчиком конструктором |

- Источник: [Встроенный язык](https://v8.1c.ru/platforma/vstroennyy-yazyk/), «Универсальные коллекции значений».

## Типы и данные

Общая система типов языка и полей БД. Составные типы поля. Тип **ХранилищеЗначения** и одноимённый объект языка для преобразования значений к формату хранилища (в т.ч. изображения).

Объектный доступ загружает объект целиком (включая вложенные таблицы как коллекции). Табличный доступ (запросы) — только чтение.

- Источник: [Работа с базой данных](https://v8.1c.ru/platforma/rabota-s-bazoy-dannykh/).

При сериализации в JSON примитивные типы и коллекции отображаются в фиксированный набор: **Строка**, **Число**, **Булево**, **Неопределено**, **Массив**, **ФиксированныйМассив**, **Структура**, **ФиксированнаяСтруктура**, **Соответствие**, **Дата**.

- Источник: [JSON](https://v8.1c.ru/platforma/json/), «Сериализация примитивных типов и коллекций».
